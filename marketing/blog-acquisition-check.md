# Blog acquisition check: home feed guide

Page: /blog/hide-youtube-shorts-and-recommendations
Prepared: 2026-10-16. Record the actual deployment date before comparing results.

## Why update this page

The existing guide already covers hiding the home feed, Shorts, and recommendations. Keep its URL and main topic rather than create another page with overlapping instructions. The update adds direct install buttons near the answer, explains what stays accessible, and matches the current popup controls while retaining older labels.

Public questions establish interest in hiding the home feed, but no keyword-volume or site-performance data was available during this update. Do not treat this topic as a proven traffic opportunity yet.

## Baseline and follow-up

Before deployment, export the previous 28 complete days of Search Console performance filtered to this exact page. Record search clicks, impressions, CTR, average position, and queries. Look for home-feed, Shorts, and recommendation-related searches. Keep country and device filters consistent.

Record store listing visits and installs for the same period wherever each store's publisher reports expose them. Record which metrics and attribution dimensions are actually available; missing data is unknown, not zero.

After deployment, compare the next 28 complete days with the baseline. Annotate other releases or promotions. Small samples and search-position changes can explain apparent gains. A before/after comparison is directional evidence, not proof of causation.

| Signal | What it tells us | Limitation |
| --- | --- | --- |
| Search Console clicks to this URL | Search visits to the guide | Does not measure install-button clicks |
| Search queries and impressions | Whether the page reaches relevant searches | Does not establish total keyword volume |
| Store listing visits | Visits reported by the store | May include other sources |
| Store installs | Acquisition reported by the store | Cannot attribute to this article without supported source reporting |
| Installs / listing visits | Store conversion, when metrics use compatible definitions | Not article-to-install conversion |

## Measurement boundary

This change adds no analytics, click collection, or extension telemetry. Article-to-store clicks are not currently measured by this change. Do not claim a complete visits-to-clicks-to-installs funnel or divide total store installs by this article's search clicks.

Before adding campaign parameters, verify that the destination store supports campaign reporting and preserves attribution through installation. If account reports cannot isolate this page, report search performance and total store acquisition separately.

## Next decision

If the guide receives relevant impressions but few clicks, review its search snippet and ranking context. If store visits grow but installs do not, review listing clarity and screenshots. If relevant search impressions remain scarce, use actual query data to choose the next topic rather than publishing another version of this guide.
